# config/ — Test Configuration Files

| File | Purpose |
|------|---------|
| `browsers.json` | Supported browsers and their Playwright types (chromium, firefox, webkit) |
| `devices.json` | Device/resolution configurations for cross-device testing |
| `network-conditions.json` | Network simulation presets (Normal, Slow 3G, Offline, etc.) |

These are read-only config references used by test scripts.
