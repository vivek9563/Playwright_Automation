================================================================================
▶  RUN WITH PLAYWRIGHT CLI  (npx playwright test)   ← NEW ✨
================================================================================

  Run ALL modules (43 tests):
    npx playwright test

  Run INDIVIDUAL modules:
    npx playwright test --project=login           ← 6 Login tests
    npx playwright test --project=dashboard       ← 16 Dashboard tests
    npx playwright test --project=organization    ← 10 Organization tests
    npx playwright test --project=projects        ← 11 Projects tests

  Run with visible browser (headed mode):
    npx playwright test --headed

  Run specific module headed:
    npx playwright test --project=login --headed

  Generate Playwright HTML report:
    npx playwright test --reporter=html
    npx playwright show-report reports/playwright-html

  Run with retries:
    npx playwright test --retries=2

  Debug a specific test (Playwright Inspector):
    npx playwright test --project=login --debug

================================================================================
STEP 0 — FIRST TIME SETUP (run once only)
================================================================================
  npm install
  npx playwright install chromium

================================================================================
STEP 1 — VERIFY .env FILE IS CONFIGURED
================================================================================
  Ensure .env file has these values set:

  APP_URL=http://localhost:5173          ← Your CRM app URL
  GMAIL_EMAIL=your@email.com            ← Sender Gmail address
  GMAIL_APP_PASSWORD=xxxx xxxx xxxx     ← Gmail App Password (not login password)
  RECIPIENT_EMAIL=recipient@email.com   ← Who receives the report email
  HEADLESS=false                         ← true = no browser window, false = visible
  BROWSER=chromium

  To get Gmail App Password:
    → https://myaccount.google.com/apppasswords

================================================================================
STEP 2 — MAKE SURE CRM APP IS RUNNING
================================================================================
  The CRM app must be running at http://localhost:5173 before executing tests.
  Start it separately in another terminal if needed.

================================================================================
▶  RUN ALL TESTS + UPDATE EXCEL + GENERATE HTML + SEND EMAIL  (ONE COMMAND)
================================================================================

  node run-all-tests-and-report.js

  OR via npm shortcut:
  npm run test:run-all

  This single command does everything:
    ✅ Runs Login tests          → updates login Excel
    ✅ Runs Dashboard tests      → updates Dashboard Excel
    ✅ Runs Organization tests   → updates Organization Excel
    ✅ Runs Projects tests       → updates Projects Excel
    ✅ Updates Master Excel      → reports/Master_Test_Report.xlsx
    ✅ Generates HTML Report     → reports/Master_Test_Report.html
    ✅ Sends Email               → to RECIPIENT_EMAIL in .env
