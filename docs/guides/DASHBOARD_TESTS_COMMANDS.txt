TROUBLESHOOTING
────────────────

Issue: "Module not found" error
  → Ensure you're in ~/Downloads/Vedak_Automation directory
  → Run: cd ~/Downloads/Vedak_Automation

Issue: "Port 5173 connection refused"
  → Start Vedak CRM application
  → Verify: http://localhost:5173 opens in browser

Issue: "Gmail authentication failed"
  → Check .env file exists in project root
  → Verify GMAIL_EMAIL and GMAIL_APP_PASSWORD are set correctly

Issue: Playwright errors
  → Run: npm install (if not already installed)
  → Or: npx playwright install
