🔄 EMAIL TROUBLESHOOTING
════════════════════════════════════════════════════════════════════

If email doesn't send:
───────────────────────

1. CHECK AUTHENTICATION:
   Error: "Invalid login"
   ├─ Verify GMAIL_EMAIL in .env
   ├─ Verify GMAIL_APP_PASSWORD is correct
   ├─ Check if 2FA is enabled on account
   └─ Regenerate app password if needed

2. CHECK FILE ATTACHMENTS:
   Error: "File not found"
   ├─ Verify Master_Test_Report.xlsx exists
   ├─ Verify test-reports/master-test-report.html exists
   ├─ Run tests first to generate files
   └─ Check file paths in script

3. CHECK NETWORK CONNECTION:
   Error: "Connection timeout"
   ├─ Verify internet connection
   ├─ Check Gmail servers are accessible
   ├─ Try again after 1-2 minutes
   └─ Check firewall settings

4. CHECK GMAIL ACCOUNT:
   Error: "Account blocked"
   ├─ Check for suspicious activity alert
   ├─ Review Google account security
   ├─ Verify app password is still valid
   └─ Contact Google support if needed

Debug Mode:
  node send-test-report-email.js
  └─ Detailed error messages in console
  └─ Helps identify exact issue
