💡 TROUBLESHOOTING
════════════════════════════════════════════════════════════════════

PROBLEM: Email not sending
  Causes:
    ├─ App password incorrect
    ├─ 2FA not enabled
    ├─ Internet connection down
    └─ Gmail account blocked
  Solutions:
    ├─ Verify GMAIL_APP_PASSWORD in .env
    ├─ Enable 2FA on Gmail
    ├─ Check internet connection
    ├─ Regenerate app password
    └─ Review Google account security

PROBLEM: Tests failing
  Causes:
    ├─ Application down
    ├─ Selectors changed
    ├─ Authentication issue
    └─ Session expired
  Solutions:
    ├─ Verify app is running on http://localhost:5173/
    ├─ Run single test: node send-test-report-email.js
    ├─ Check credentials in .env
    ├─ Clear sessions/session-data.json

PROBLEM: Reports not generated
  Causes:
    ├─ Tests didn't complete
    ├─ Disk space full
    ├─ Permission issues
    └─ File path incorrect
  Solutions:
    ├─ Check test output in terminal
    ├─ Verify disk space: df -h
    ├─ Check file permissions: ls -la
    ├─ Verify report script exists

PROBLEM: Email attachments missing
  Causes:
    ├─ Report files not created
    ├─ File names incorrect
    └─ Path not found
  Solutions:
    ├─ Run tests first to generate files
    ├─ Check file locations
    ├─ Verify file names match script
