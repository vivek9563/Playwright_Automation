ENVIRONMENT VARIABLES
================================================================================

Required (must set in .env):
  APP_URL              - Application URL (http://localhost:5173/)
  GMAIL_EMAIL          - Gmail account (vivek.k@vedak.com)
  GMAIL_PASSWORD       - Gmail app password

Optional:
  HEADLESS             - true/false (default: false)
  SLOW_MO              - Milliseconds between actions (default: 500)
  TIMEOUT              - Test timeout in ms (default: 30000)
  LOG_LEVEL            - debug/info/warn/error (default: info)
  LOG_FILE             - Log file path (default: ./logs/test-execution.log)
  REPORT_PATH          - Report directory (default: ./reports)
  SCREENSHOT_PATH      - Screenshot directory (default: ./screenshots)

================================================================================
TEST EXECUTION FLOW
================================================================================

Each test follows this pattern:

1. Launch Browser
   - Chromium or Firefox based on test type
   - Set viewport size (desktop: 1920x1080, mobile: 390x844)
   - Apply network conditions if applicable

2. Navigate to App
   - Load http://localhost:5173/ or custom APP_URL
   - Wait for network idle or specific wait conditions

3. Perform Test Actions
   - Click buttons, fill forms, interact with elements
   - Take screenshot after each action step
   - Log all actions with timestamps

4. Verify Results
   - Check for expected elements
   - Verify user state (logged in/out)
   - Check for error/success messages

5. Generate Report
   - Record test result (PASS/FAIL)
   - Log duration and any errors
   - Capture screenshot on failure

6. Cleanup
   - Close browser/context
   - Generate HTML report
   - Archive logs

================================================================================
TROUBLESHOOTING
================================================================================

Issue: "GMAIL_PASSWORD not set in .env"
Fix: Copy .env.example to .env and add your Gmail app password

Issue: "Navigation timeout after 30000ms"
Fix: Make sure your app is running on http://localhost:5173/

Issue: "Firefox/Chrome process exited unexpectedly"
Fix: Reduce SLOW_MO in .env to 100 and try again

Issue: "OAuth popup didn't open"
Fix: Check if Google is blocking automation for your account
     Or run the test again - sometimes it takes a retry

Issue: "Screenshots not being saved"
Fix: Check disk space and permissions in ./screenshots/ directory

Issue: "Tests are too slow"
Fix: Reduce SLOW_MO in .env file (default is 500ms)
     Or run in headless mode: HEADLESS=true npm run test:ui
