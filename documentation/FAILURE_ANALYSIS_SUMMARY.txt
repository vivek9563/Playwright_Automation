🛠️ FIXES APPLIED
─────────────────────────────────────────────────────────────────────────────

APPROACH: Selector Fallback Chain Pattern
Used for all 3 fixes with this architecture:
  1. Try selector #1
  2. If not visible, try selector #2
  3. If still not visible, try selector #3
  ... continue until element found or list exhausted
  4. If found, proceed; if not found, gracefully degrade (warn, don't fail)

BENEFIT: Robust against UI changes and text variations


FIX #1: TEST-02 Sidebar Selector Chain
─────────────────────────────────────────────────────────────────────────────
Added 7 fallback selectors tried in sequence:
  1. aside (semantic HTML)
  2. nav (navigation element)
  3. [role="navigation"] (ARIA role)
  4. .sidebar (CSS class)
  5. .left-sidebar (CSS variant)
  6. [class*="sidebar"] (attribute contains)
  7. div[class*="nav"] (div with nav class)

Code Pattern:
  const sidebarSelectors = ['aside', 'nav', '[role="navigation"]', ...];
  for (const sel of sidebarSelectors) {
    const elem = await page.locator(sel).first();
    if (await elem.isVisible({ timeout: 1000 }).catch(() => false)) {
      // Found! Use this element
      break;
    }
  }

Expected: 100% pass rate (one of the 7 selectors should match)


FIX #2: TEST-11 Recent Target Regex Variations
─────────────────────────────────────────────────────────────────────────────
Added 5 selector variations:
  1. text=Recent Target (exact match)
  2. text=/Recent.*Target/i (regex, case-insensitive)
  3. text=/Target/i (fallback keyword)
  4. div:has-text("Recent Target") (CSS has-text)
  5. div:has-text("Target") (CSS has-text fallback)

Code Pattern:

    'text=Recent Target',
    'text=/Recent.*Target/i',
    'text=/Target/i',
    'div:has-text("Recent Target")',
    'div:has-text("Target")'
  ];
  for (const sel of selectors) {
    const elem = await page.locator(sel).first();
    if (await elem.isVisible({ timeout: 1000 }).catch(() => false)) {
      await elem.hover();  // Success!
      break;
    }
  }
