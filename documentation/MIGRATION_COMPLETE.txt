TROUBLESHOOTING
===============

Tests not running?
  → Check if test files exist in modules/[MODULE]/test-cases/
  → Verify scripts have correct paths to imports
  → Run: ls -la modules/login/test-cases/

Can't find a file?
  → Use: find ~/Downloads/Vedak_Automation -name "filename"
  → Check documentation/FOLDER_STRUCTURE_GUIDE.txt
  → Most files should be in modules/ or reports/

Email not sending?
  → Check .env file has GMAIL_APP_PASSWORD
  → Verify email paths: features/2026-10-28-email-automation/

Screenshots not found?
  → Check: screenshots/current/[MODULE]/
  → Or: screenshots/archive/ (if >30 days old)
